# 🌑 Landing Page Mundo Invertido: Uma Jornada pelo Frontend no Mundo Invertido de Stranger Things!


E aí, meu 🐙! Prepare-se para ser transportado para a atmosfera misteriosa de Stranger Things com esta **Landing Page responsiva e envolvente** inspirada no icônico Mundo Invertido! 👾

Este projeto foi meticulosamente desenvolvido em **HTML, CSS e JavaScript** para criar uma experiência que captura a essência sombria e cativante da série, enquanto demonstra minhas habilidades em Frontend:

* **Estética Sombria e Imersiva:** Design visual que remete diretamente ao Mundo Invertido, com cores e texturas características.
* **Design Responsivo:** Adaptável a diferentes tamanhos de tela, garantindo a imersão tanto no desktop quanto no celular.
* **Interatividade Sutil:** Elementos que reagem à interação do usuário, aumentando o engajamento e a sensação de mistério.
* **Animações e Transições:** Movimentos suaves que contribuem para a atmosfera e a fluidez da navegação.
* **Boas Práticas de Frontend:** Código limpo, semântico e modular para fácil manutenção e escalabilidade.

É uma exploração de como o Frontend pode ir além da funcionalidade, criando uma verdadeira **experiência temática e emocional** para o usuário! Vem desvendar os segredos do Mundo Invertido! 😉

### **🚀 Tecnologias Envolvidas:**

* **HTML5:** Estrutura semântica e base da página.
* **CSS3:** Estilização avançada, responsividade, animações e efeitos visuais para criar a atmosfera do Mundo Invertido.
* **JavaScript (ES6+):** Implementação de interatividade e dinamismo nos elementos da página.

### **⚙️ Como Rodar o Projeto (Localmente):**

1.  **Clone este repositório:**
    ```bash
    git clone [https://github.com/miriaamaral/Landing-Page-Mundo-Invertido.git](https://github.com/miriaamaral/Landing-Page-Mundo-Invertido.git)
    ```
2.  **Entre na pasta do projeto:**
    ```bash
    cd Landing-Page-Mundo-Invertido
    ```
3.  **Abra o arquivo `index.html` no seu navegador.**
    * Para uma melhor experiência de desenvolvimento, considere usar a extensão "Live Server" no VS Code.
